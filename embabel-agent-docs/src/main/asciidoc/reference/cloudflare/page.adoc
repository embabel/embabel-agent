[[reference.cloudflare]]
=== Cloudflare Workers AI decision models

`CloudflareModelFactory` is an optional JVM provider with id `cloudflare`.
It implements Workers AI's typed REST route and envelope, separately from generic SystemOne endpoints.
Add `com.embabel.agent:embabel-agent-starter-cloudflare` to use its optional auto-configuration.
Starter presence alone creates no factory, named service or default.

==== Supported catalog and verification status

[cols="2,1,1,1",options="header"]
|===
|Full model id |Body selector |Published model size |Hosted context tokens
|`@cf/cloudflare/clef` |`clef` |27B |65,536
|`@cf/cloudflare/clef-flash` |`clef-flash` |9B |24,576
|===

These figures describe the two hosted targets, from the
https://developers.cloudflare.com/workers-ai/models/clef/[official CLEF model schema] and
https://developers.cloudflare.com/workers-ai/models/clef-flash/[official Flash model schema].
The https://github.com/cloudflare/cloudflare-docs/blob/d9156dd747599535d9c1e290f0e155735ed11d58/src/content/changelog/workers-ai/2026-10-09-clef-omni-workers-ai.mdx[October 9, 2026 changelog, pinned at d9156dd]
resolves older Flash 64K claims: the hosted window was reduced to 24K. Self-hosted weight limits are separate.
`@cf/cloudflare/clef-omni` exists in the hosted family but is unsupported by this initial catalog.
This adapter accepts text and typed proposition/choice/rating questions; images, audio, video and structured state are unsupported.

[IMPORTANT]
====
The published schemas say long text state is truncated to fit the model's token limit.
No verified nontruncation flag is available. Request byte caps, context sizes and token usage do not prove that
all supplied facts were retained. This integration has schema/fixture and loopback HTTP validation; live paid
Cloudflare inference is *unrun*. Exact hosted numeric precision, runtime and deployed revision remain *unknown*.
Do not treat these examples as evidence for unattended high-stakes decisions.
====

Replace the placeholder with the account that will run inference and supply the Bearer token through your application's
secret configuration for `embabel.agent.platform.models.cloudflare.api-key`.
The account id must be 32 hexadecimal characters. No token is needed to construct the factory, inspect its local
catalog or register services. A missing or blank token fails execution as unavailable before HTTP; the token supplier
is evaluated only on a call. Enabling the factory alone does not register a service or choose a default.
Named service registration performs no startup discovery or billable capability probe.

your workload before relying on results; live provider compatibility remains unvalidated here.

==== REST mapping and bounds

The adapter posts to
`https://api.cloudflare.com/client/v4/accounts/{account-id}/ai/run/{full-model-id}` with Bearer authentication.
It derives the request's `model` selector from the supported full id, with no independent selector override.
It validates the REST success/error envelope, unwraps `result` once and requires the returned model identity to
match the requested full id or its corresponding short selector. Provenance records that requested full id;
it does not attest hosted weights, runtime revision or calibration.

Named typed questions are encoded as ordered `q001`-style wire ids, then mapped back to the caller's public names.
The supported text profile requires 1–64 questions, nonblank instructions, 2–255 choice options and 2–10 rating levels.
Profile violations and serialized UTF-8 request overflow raise `UnsupportedDecisionException` before token resolution
or HTTP. Operational/response failures retain typed failure outcomes; they do not turn into fabricated answers.

[cols="2,1,2",options="header"]
|===
|Property under `embabel.agent.platform.models.cloudflare` |Default |Accepted bound
|`timeout` |20 seconds |Positive, at most 300 seconds; covers the entire exchange/body
|`max-request-bytes` |262,144 (256 KiB) |1–1,048,576 serialized UTF-8 bytes
|`max-response-bytes` |1,048,576 (1 MiB) |1–1,048,576 bytes
|`model-names` |Both supported full ids |Unique subset of the initial catalog
|===

Byte limits reject known local overflow; they are not token or fact-retention guarantees.
The HTTP client disables automatic retries and redirects and bounds response bodies and metadata.

==== Numeric evidence

The adapter preserves provider-reported proposition probability, complete choice probabilities, rating probabilities,
expected zero-based rating index and raw confidence through the shared strict decoder.
It requires finite in-range probabilities covering the exact domain, sums within `1e-6` and expected scores
consistent with their distribution within `1e-6`. Malformed or rounded evidence outside those limits is rejected.
No tolerance widening, normalization, confidence-formula conversion or calibration attestation is performed.

Published reference examples and inspected serving implementations differ in precision and confidence semantics.
A schema match or a strict normalized distribution does not prove a native head ran.
Hosted response precision and confidence meaning still need live validation; no paid request was made for these examples.
See <<reference.decision-providers>> for generic service selection, prompted local LLMs and independently operated
SystemOne endpoints. The separate question of a verified native local CLEF runtime remains open.
